# Example data for image analysis

This folder contains an example image file (IMG_1165.jpg) and its corresponding transects and counts (RoiSet_1165.zip). Including all image files is not possible due to file size constaints. Images such as this one were used to generate all counts data in the file densities.csv

To use: import both files into ImageJ software (version 1.54j was used). Result will show transects and counts for the example image. See the file code number in the densities.csv file to compare.
