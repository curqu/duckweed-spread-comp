# Example data for image analysis

This folder contains example image files (eg. IMG_1100.jpg) and its corresponding transects and counts (eg. RoiSet_1100.zip). Including all image files is not possible due to file size constaints. Images such as these were used to generate all counts data in the file densities.csv

To use: import image file along (IMG_11XX.png) with corresponding objects (RoiSet_11XX.zip) into ImageJ software (version 1.54j was used). Result will show transects and counts for the example image. See the file code number in the densities.csv file to compare.
